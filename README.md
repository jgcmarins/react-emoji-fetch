# React Emoji Fetch
A react app that helps you find an emoji

## Live demo at
#### [https://jgcmarins.github.io/react-emoji-fetch/](https://jgcmarins.github.io/react-emoji-fetch/)

## Usage
#### Installation
```bash
npm install
```

#### Run
```bash
npm start
```
